How this works: When you approve a school, the system checks which term is currently active for that school's state and sets the subscription expiry to the end of that term (or the end of the Nth term if they paid multiple). If no calendar is set for a state, it falls back to 3 months per term.

To edit: Select a state → change the dates → tap Save Dates. Changes take effect immediately for new approvals.
